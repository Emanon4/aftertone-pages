# 余音 · Aftertone

下一首，你的单曲循环。

[打开听音室](https://emanon4.github.io/aftertone-pages/)

此仓库仅包含 GitHub Pages 网页构建产物，已连接独立 Cloudflare API，提供搜索、试听、Jev 辅助筛选及个人模型设置。默认深色，可从页脚切换浅色；完整收听可选择六个官方音乐平台。
